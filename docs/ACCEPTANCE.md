# 首版验收清单

版本：v0.1 / 2026-09-26。**以下均为待执行要求，不是已通过结果。**

## 1. 验收分层与完成门槛

- **单元测试**：纯解析、时间函数、状态转换与事件结构；精确断言，不容差蒙混。
- **浏览器端到端测试**：实际页面导入、点击/按键、文件下载、存储刷新、真实媒体播放。
- **人工体验**：Windows Chrome 或 Edge，真实有语音材料，核对听感与可用性。

完整验收 = AC-01～24 都有证据，全部必需行为通过，且实际完成至少一次 Windows 浏览器真实语音试用。
如果代码/自动测试通过但拿不到真实语音或 Windows 环境，可以交付“工程验收通过，人工试用待验证”，**不能写全部完成**。
不能只用截图、构建成功或 mocked currentTime 代替真实播放验证。

## 2. 可复现测试材料

- 输入字幕：fixtures/basic.cues.json、fixtures/basic.en.srt。
- 工程媒体：20 秒合成视频或音频，生成方式见 fixtures/README.md。不包含真实语音，只验证时间行为。
- 无效输入在测试中从样例克隆后修改，不破坏标准样例。
- 真实材料：由用户或实现者合法持有、5～10 分钟、已确认基本同步的英语语音和字幕。
- 正常前台、1 倍速；记录系统、浏览器和版本。
- 时间纯函数用毫秒精确值；真实浏览器显示边界/自动暂停允许最多 150ms 的观察误差，不应将媒体 seek 校正后的读数冒充实际暂停误差。
- 若同一条测试失败，记录原始失败和原因，不靠删样例、扩大容差或只重跑成功的一次宣称稳定。

## 3. 用例

### 导入与数据

- [ ] **AC-01：JSON 正常输入。** 导入标准样例得到 7 条，所有 start/end/id/src/tgt 保留；c0003 缺译文不妨碍使用。
- [ ] **AC-02：SRT 子集。** 样例、BOM、CRLF、多行原文、末尾无空行、非连续数字序号、纯数字正文均正确。生成 ID 顺序稳定，译文为 null。
- [ ] **AC-03：明确拒绝坏输入。** 分别测试空轨、重复 ID、空原文、非法类型、非安全整数、start>=end、乱序、重叠、坏 SRT 时间、不支持版本；展示定位错误，不静默丢条/排序/改时。
- [ ] **AC-04：输入与媒体配对。** 字幕超出媒体 >100ms 拒绝；容差内不改原始时间，review 末条仍能在媒体 ended 时完成；显示名称/时长/条数并确认。不支持或损坏媒体提示解码问题。取消/坏的新输入不覆盖已加载会话。

### 连续延迟与边界

- [ ] **AC-05：本地真实媒体。** 文件选择器导入后实际播放、暂停和拖动；切换新媒体后旧 URL 释放；同一文件可重选。至少分别验证一个视频与一个纯音频文件。
- [ ] **AC-06：不预读。** B 模式 D=1000，在 0～1999ms 不显示 c0001；原生字幕、隐藏 DOM 面板或译文区不能提前显示原文。译文默认隐藏。
- [ ] **AC-07：B 的精确时间表。** fixtures/README 中全部查找点用纯函数逐一断言；特别是 t=3500 时 audio=c0002、display/action=c0001，t=4000 时 display=c0002，t=6000 时 display=null。
- [ ] **AC-08：短条目与间隙。** c0005 原区间只有 500ms，在 D=1000 下仍显示完整 [15000,15500)；不会因 D 大于条目时长而消失。间隙不粘住前条。
- [ ] **AC-09：暂停与改 D。** 用户暂停不因现实时间过去而换字幕。D 改为 0/3000 后立即按同一媒体位置计算，时间戳和 currentTime 不变，译文重新隐藏；D 仅允许 0～3000 且步长 100。
- [ ] **AC-10：片尾不丢条。** 20 秒媒体自然结束、D=1000 时补看区含 c0006/c0007，各译文隐藏，选择目标与 T/R/U 一致。D=0 无额外尾条；用户直接 seek 到末尾不伪造自然 ended 补看；末尾“从头播放”仅在主动触发时重启。

### 核对、重听与控制

- [ ] **AC-11：完整片段核对。** review 从 c0001 开头播放；播放途中即使手动暂停也不显示原文。到 3000ms 自动暂停显示 c0001，T 可揭示译文；继续从 c0002 起点播放，听的过程中两行均隐藏。
- [ ] **AC-12：连续条目边界。** c0001.end=c0002.start=3000 时只暂停一次，不把 c0002 原文提前显示；继续不会立刻重复暂停。核对最后一条后正常结束。
- [ ] **AC-13：重听对象不串句。** B 在 t=3500、D=1000 时按 R，重听 c0001 而不是 c0002；起点 1000、终点 3000，途中无旧字幕，完成显示 c0001，译文隐藏，按继续从 3000 恢复 B。
- [ ] **AC-14：取消与快速操作。** 连续 R、seek、切模式、换素材，不产生多个播放循环或旧回调改写新状态；seek 后保持暂停。review seek 到 5500ms 后选 c0003，播放从 6500ms 开始；尾后无目标时给出明确状态。
- [ ] **AC-15：译文与没听懂。** T 只针对可见目标；c0003 显示无译文提示；R 后译文不沿用；切条/seek/切模式/改 D 清除揭示。U 标记正确 ID，按钮反馈和日志一致。
- [ ] **AC-16：键盘不抢输入。** Space/T/R/U 与按钮一致；长按不重复计数；滑块/输入框/选择器/可编辑区内不拦截；按钮 Space/Enter 不双触发；无目标时快捷键不绕过禁用。无鼠标也能导入与完成基本练习。
- [ ] **AC-17：隐藏页与播放失败。** 标签页隐藏时暂停，返回保持暂停，日志有 hidden 原因。play() 被拒绝或解码失败时不显示正在播放，不丢失已保存记录。

### 安全、日志与交付

- [ ] **AC-18：纯文本与本地数据。** 原文/译文含 `<img src=x onerror=...>`、`<script>` 时只显示文本、不执行、不触发对应请求。网络观察确认导入后无外部媒体/字幕上传、无第三方分析/CDN请求；开发资源请求不算上传。
- [ ] **AC-19：可解释日志。** 执行导入→播放→T→U→R→继续→改 D→切模式→seek；导出逐行 JSON 可解析、seq 连续且 event_id 唯一、ID 与操作发生时的上下文一致；配置变化有 from/to；边界事件不双计。
- [ ] **AC-20：持久化、失败和快照。** 刷新后可导出历史；多会话不混淆；导出等待队列提交。模拟 IndexedDB 写失败，显示失败且可导出未保存记录；不能伪称已保存。已提交与重试事件不会重复。
- [ ] **AC-21：布局可用。** 1440×900 和 1024×768 桌面尺寸无页面横向溢出，媒体/字幕/主要控制均可操作；长文本完整换行，译文展开不使按钮跳位；状态、操作目标、模式与 D 是否生效清晰。
- [ ] **AC-22：测试与构建。** 实际运行 npm run typecheck、npm test、npm run test:e2e、npm run build；保留结果。E2E 包含至少一次真实媒体从起点播放到片段边界，不能全是 synthetic event；区分单元、浏览器与人工证据。
- [ ] **AC-23：启动与运行说明。** README 有实际可用的 Node 要求、安装/启动/测试命令、固定 localhost 端口、WSL→Windows 浏览器访问方法、媒体格式边界和日志数据位置/导出方法。不擅自改防火墙、不开放公网。
- [ ] **AC-24：真实短片试用。** Windows Chrome/Edge，用已匹配字幕的 5～10 分钟真实英语材料试正常字幕/延迟 B/片段核对；完成播放、重听、揭示与日志导出。人工听至少 10 个片段的结尾，记录是否截尾/听到下一条；这是可用性记录，不宣称学习提升。仅合成媒体不算通过。

## 4. 时间与事件的专项断言

- 真边界 overshoot_ms = max(0, observed_boundary_ms - cue.end_ms)，记录**暂停/seek 校正之前**观测的位置。
- 至少选连续边界 c0001→c0002 与短条目 c0005 测真实暂停；不能只测试最后一条 ended。
- 逻辑不提前暂停；前台实际暂停观察误差 <=150ms。超过时记录失败与设备负载，不用更宽容差掩盖。
- 因视频/浏览器音频缓冲产生的真实听感是否可接受，仍以 AC-24 人工听感单独报告。
- 通过“播放器当前时间被设回 end_ms”不能证明实际尾音未被截断/没有串入下一句。

## 5. 交付证据格式

实现者创建 docs/VERIFICATION.md，至少包含：

```text
实现版本/日期：
环境：OS / 浏览器版本 / Node 版本
启动方式：
自动检查：命令、退出码、真实摘要
逐项结果：AC-01 ... AC-24；通过 / 失败 / 未验证，证据位置
真实播放证据：媒体生成来源、关键边界观察值
人工试用：材料来源、模式、问题记录（没有则写未验证）
未解决问题：影响、复现步骤
实际改动审查：改动文件、是否包含无关/生成噪音
```

不得预先勾选本清单。截图与报告不提交用户原始视频、敏感文件名或未授权内容。
