# 可复现验收样例

## 1. 已有文件

- basic.cues.json：7 条人工编写的虚构英文字幕，含中文与一条缺译文。
- basic.en.srt：完全相同的原始时间和英文文本，用于 SRT 导入。
- 两者都不是某部影片的转录，不包含版权媒体。
- 本目录不含媒体二进制；实现 agent 按需生成到 ignored 的 generated/ 或测试临时目录。

## 4. 合成媒体建议

以下命令是给实现者使用的可复现配方，本次文档准备没有执行生成。
先确认输出文件不存在，避免覆盖。ffmpeg 不应使用 -y 无条件覆盖。

```bash
mkdir -p generated
ffmpeg -f lavfi -i 'color=c=0x18212b:s=640x360:r=30:d=20' \
  -f lavfi -i 'sine=frequency=440:sample_rate=48000:duration=20' \
  -c:v libx264 -pix_fmt yuv420p -c:a aac -t 20 -shortest generated/timing-20s.mp4
ffmpeg -f lavfi -i 'sine=frequency=440:sample_rate=48000:duration=20' \
  -c:a pcm_s16le -t 20 generated/timing-20s.wav
```

视频只有纯色背景与提示音，**不能检验英文听力、ASR 准确性或字幕语义同步**。
若测试用 Chromium 缺少某视频解码器，应报告环境限制、保留 WAV 真播放覆盖，并在实际 Windows 浏览器补测视频；不得把视频支持要求直接删掉。
将生成命令纳入测试准备说明；不要要求测试时联网下载一段来历不明的视频。

## 5. 负例建议

测试内克隆 JSON 分别构造：c0002.id 重复、start=end、负值、浮点/超大时间、非字符串文本、重叠、乱序、不支持 schema、空数组。
SRT 变体测试 BOM/CRLF/多行/无尾空行/纯数字正文；错误变体有非法时间与缺正文。
恶意正文仅作为纯文本测试，使用不会真实泄露数据的本地标记；不要连接第三方攻击站点。
